# Contributing

This repository is used for the development of the drone project. Keep the workflow simple and make sure the repository remains understandable for everyone.

## Simple rules

* Use **Issues** to describe tasks, bugs, ideas, or tests that need to be done.
* Assign yourself to an issue when you start working on it.
* Create a **branch** when your work requires significant changes to the repository. Small changes may be committed directly.
* Make regular **commits** with short and meaningful messages.
* **Do not** commit temporary files, build files, or personal configuration files.
* **Test** your work before considering an issue completed.
* For **hardware experiments**, keep useful measurements, photos, or oscilloscope captures in the corresponding issue when relevant.
* Update the **documentation** when a change affects how the system is built or used.
* When several people are working on related parts, **communicate** before making changes that may affect their work.

## Branches

Use simple and descriptive branch names, for example:

`imu-driver`
`motor-test`
`radio-communication`
`battery-measurement`

## External contributions

Contributions from people outside the project team are welcome through Pull Requests. Please describe what was changed, why, and how it was tested.
