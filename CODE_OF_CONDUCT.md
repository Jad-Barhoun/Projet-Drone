# Code of Conduct

This project is developed as part of an academic project. Contributors are expected to collaborate respectfully and professionally.

In particular:

* Be respectful and constructive in discussions and code reviews.
* Give clear and helpful feedback.
* Respect the work and contributions of other team members.
* Use issues and pull requests to discuss technical decisions when appropriate.
* Do not include private, confidential, or inappropriate content in the repository.

Disagreements should be resolved through technical discussion and, when necessary, with the project supervisor.
